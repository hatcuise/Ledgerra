# Ledgerra v0.14.0

This release adds reviewed native statement import and reversible recognition of
transfers between accounts. It also includes the HomeBank 5.10.3 source-based gap
audit and the remaining implementation roadmap.

## Native statement imports

- Inspect OFX/QFX bank and credit-card statements, including legacy SGML and XML.
- Read ordinary QIF and HomeBank .xhb transactions without an AI provider.
- Map each source account to a distinct owned account with the same currency where known.
- Preview payees, categories, dates, amounts, references and tags before saving.
- Keep stable OFX FITID identities through transaction edits, backups and restores.
- Reject repeated FITIDs rather than adding a second copy of the same bank transaction.

This is **transaction import**, not complete HomeBank wallet migration. Split rows,
void/reminder rows, FX transfer migration, investment activity, source reconciliation
history, budgets and schedules need additional support. Warnings and validation
identify unsupported records; opening balances are not changed automatically.

## Transfer recognition

- New ordinary entries and import batches look for their existing opposite entry.
- Match equal amounts, owned accounts, same currency and nearby dates.
- Auto-link only mutually unique candidates with a nontrivial shared reference or
  transfer descriptions identifying both owned accounts; generic wording is insufficient.
- Scan previously imported entries in Bookkeeping with a configurable 0–7 day window.
- Review and manually link ambiguous suggestions.
- Undo matches without deleting either original transaction.
- Protect reconciled/split/already-linked entries and retain account balances and dates.

## Data integrity and audit

- Backup format 5 includes bank identities and recognized-transfer undo history;
  formats 2, 3 and 4 remain readable. Older backends cannot read format 5.
- Preserve imported entry metadata when ordinary transactions are edited.
- Prevent account moves that would silently reinterpret a transaction's currency.
- Clear all bookkeeping/matching records when a user explicitly clears account data.
- Add a 378-capability inventory, 813-control documentation index, 197-identifier
  source-model index and phased roadmap from the uploaded HomeBank 5.10.3 archive.
  The inventory distinguishes baseline gaps, adaptations, recommendations and
  Ledgerra extensions; it does not claim complete HomeBank parity.

## Validation

166 backend tests, 134 frontend tests, production frontend build and four real
Chromium/PostgreSQL workflows passed locally. The real HomeBank sample wallet was
inspected as 8 accounts and 742 supported entries without committing its data.
Schema reinitialization preserved the existing local transaction count.

## Synology update

Back up PostgreSQL before updating. Keep the existing project name, database volume,
credentials and signing/data-protection settings. After the GitHub Release workflow
succeeds, pull both `latest` images and rebuild the existing project. No YAML tag
change is required when already using `latest`. Review imports and transfer matches
before reconciling statements. Existing stored transactions are not rescanned or
reclassified merely because the application restarts.
