# v0.17.0 — Mint-style spending insights and alerts

Adds an **Insights** page and a shared dashboard spending-alert summary:

- Net spending, cash flow, category/payee breakdowns and same-day historical
  comparisons using up to three recorded prior months.
- Budget threshold, overspending and spending-pace alerts with carryover support.
- Large-purchase alerts and unusual category purchases using a five-sample minimum
  and median comparisons.
- Interactive cumulative spending chart, daily data table, transparent straight-line
  month-end estimates and current/past/future-month handling.
- Per-user preferences, dismiss/restore actions, escalation from budget warnings to
  overspending, and links to exact purchase or time-zone-aware category evidence.
- Browser-local month/day boundaries, including New York midnight boundaries, and
  a month selector accessible on mobile. Mobile navigation uses one scrolling row
  so it no longer covers several rows of content.

Transfers are excluded, refunds reduce spending and splits are counted once.
Missing FX rates pause monetary alerts/comparisons/projections and label known
amounts explicitly. These are in-app review prompts; no external notifications,
AI credentials or bank-connection credentials are required.

Schema changes are additive and leave financial rows intact. JSON backup is now
version 7 and includes insight preferences/dismissals; versions 2–7 remain supported
for restore. Preserve the database and bank keyring during Synology updates.

Validation: **202 backend tests** (17 domain, 185 API), **143 frontend tests**, the
production frontend build and **nine PostgreSQL/Chromium workflows** pass. Browser
checks cover preferences/dismissals after reload and backup/restore, exact purchase
evidence, New York month boundaries, mobile layout and all previous import/banking/
bookkeeping flows. Existing transaction counts were unchanged by schema initialization.
The graph refresh was attempted; the graphify executable is unavailable here.

See [spending insight setup and calculation rules](../spending-insights.md).
